# Amazon SNS Deployment

## Overview

Amazon Simple Notification Service (SNS) is used to send monitoring notifications generated by CloudWatch alarms.

## Architecture

```text
CloudWatch
    |
    v
CloudWatch Alarm
    |
    v
SNS Topic
    |
    v
Email Subscription
```

## SNS Topic

An SNS topic acts as the notification channel for infrastructure monitoring alerts.

Example:

```text
employee-leave-monitoring-alerts
```

## Subscription

An email subscription is configured for the SNS topic.

The email endpoint must be confirmed before notifications can be delivered.

## Notification Flow

```text
EC2 Metrics
     |
     v
CloudWatch
     |
     v
Alarm Triggered
     |
     v
SNS Topic
     |
     v
Email Notification
```

## Use Cases

SNS notifications can be used for:

* High EC2 CPU utilization
* Infrastructure threshold violations
* Application availability issues
* Other CloudWatch alarm conditions

## Security

SNS topic access is controlled through AWS IAM policies and topic policies where required.

Sensitive information should not be included in notification messages.
